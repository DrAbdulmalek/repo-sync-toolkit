# حزمة تنفيذ المرحلة 1 محليًا — برومبت GenSpark v4

هذه الحزمة تنفّذ **المرحلة 1** (تصنيف ومعالجة ودمج الـ131 PR) على جهازك أنت،
حيث يبقى توكن GitHub محليًا ولا يمر عبر أي خدمة خارجية.

## المتطلبات
- `gh` CLI (https://cli.github.com) — مصرّح بحسابك: `gh auth login`
- `git` + `python3`

## التشغيل
```bash
export GH_TOKEN=$(gh auth token)     # أو الصق توكنك بصلاحية repo
bash 10_inventory.sh                 # الجرد الحي (قراءة فقط)
bash 20_merge_a_security.sh          # الفئة أ: الأمنية (بوابة CI + نسخة احتياطية قبل كل دمج)
bash 25_merge_b_map6.sh              # الفئة ب: IFM#78 + الخارطة الستة + تذكير بنود التكامل
bash 30_dependabot.sh                # الفئة ج: الدفعي الآمن (الخمسة الكبيرة مستثناة)
bash 40_drafts_triage.sh             # الفئة د: تقرير قرار للمسودات (توحيد Harness وGDRIVE_POINTER)
bash 60_license_audit.sh             # بعد كل دفعة: يجب أن يخرج 0
```

## الأمان
- **محاكاة افتراضيًا**: كل أوامر الكتابة تُطبع ولا تُنفذ. للتطبيق الفعلي:
  `DRY_RUN=0 bash 20_merge_a_security.sh` … إلخ.
- قبل كل دمج: `premerge_gate` (CI أخضر + حالة الدمج) ثم `backup_pr`
  (وسم `pre-merge/pr-<n>` + حفظ JSON الـPR في `backups/`).
- كل عملية تُسجّل في `logs/phase1_run_*.log`.
- ممنوع في هذه الحزمة (من نص البرومبت): دفع مباشر إلى main، تعديل forks،
  إعادة كتابة التاريخ، الكتابة على فرع `alphacode/artifacts`، وأي أمر undo خام.
- لا توكن مكتوب في أي ملف — يقرأ من متغير البيئة `GH_TOKEN` فقط.

## ما لا تغطيه الحزمة
- قرارات المالك المعلقة الأربعة (إعادة كتابة التاريخ، gui/desktop، سقف numpy،
  proposals ألفا-كود) — توثيق فقط دون تنفيذ.
- الفئة هـ (الإغلاقات الميتة) — بعد فحص التعارض الفعلي من جهازك.
- بند التحقق الأمني المستعرض في `20_merge_a_security.sh` فحص نمطي استرشادي؛
  راجع نتائجه يدويًا قبل الحسم.
